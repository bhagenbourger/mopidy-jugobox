# Install the Jugobox

## Install UV
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
source $HOME/.local/bin/env
```

## Set environement variables
```bash
JUGO_USER=<set your username>
JUGO_HOST=<set your jugobox host>
```

## Install the Jugobox
Connected to the raspberrypi, create `~/dist` folder.
```bash
mkdir ~/dist
``` 

From your local machine, copy wheel generated by `uv run`:
```bash
scp github.com/bhagenbourger/mopidy-spotify/dist/mopidy_spotify-0.1.dev690+g5aafba12d-py3-none-any.whl $JUGO_USER$@$JUGO_HOST$:/home/$JUGO_USER$/dist/.
scp github.com/bhagenbourger/mopidy-jugobox/dist/mopidy_jugobox-0.1.dev2+g3af24912f.d20260325-py3-none-any.whl $JUGO_USER$@$JUGO_HOST:/home/$JUGO_USER$/dist/.
```

Connected to the raspberrypi, install jugobox with it dependencies:
```bash
# Install system dependencies
sudo apt install --no-install-recommends libcairo2-dev libgirepository-2.0-dev libgstreamer1.0-dev libgstreamer-plugins-base1.0-dev gstreamer1.0-tools gstreamer1.0-pulseaudio gstreamer1.0-plugins-base gstreamer1.0-plugins-good gstreamer1.0-alsa

# Check alsasink
gst-inspect-1.0 alsasink

# Create jugobox folders
mkdir ~/jugobox && cd ~/jugobox

# Create venv
uv venv --system-site-packages

# Install mopidy-spotify (custom version)
uv pip install ~/dist/mopidy_spotify-0.1.dev690+g5aafba12d-py3-none-any.whl

# Install mopidy-jugobox
uv pip install ~/dist/mopidy_jugobox-0.1.dev2+g3af24912f.d20260325-py3-none-any.whl
```

Connected to the raspberrypi, create mopidy config:
```bash
mkdir -p ~/.config/mopidy
vi ~/.config/mopidy/mopidy.conf
```

```toml
[audio]
output = alsasink

[file]
enabled = true
media_dirs = ~/jugobox|Home

[m3u]
enabled = true
base_dir = ~/jugobox

[http]
enabled = true
hostname = <your jugobox ip>
port = 6680

[spotify]
enabled = true
authentication_provider = spotify_direct
refresh_url = http://<hostname>/callback
cache_credentials_path = ~/.config/mopidy/credentials.json

[jugobox]
enabled = true
nfc_enabled = true
config_path = ~/.config/mopidy/jugobox.json
```

Run mopidy:
```bash
~/jugobox/.venv/bin/mopidy -o "spotify/client_id=$SP_CLIENT" -o "spotify/client_secret=$SP_SECRET"
```

Test:
```bash
curl -X POST -H "Content-Type: application/json" -d '[
  {"jsonrpc": "2.0", "id": 1, "method": "core.tracklist.clear"},
  {"jsonrpc": "2.0", "id": 2, "method": "core.tracklist.add", "params": {"uris": ["spotify:track:0KQFtDbj2NfrQRrZMgSKwY"]}},
  {"jsonrpc": "2.0", "id": 3, "method": "core.playback.play"}
]' http://$JUGO_HOST:6680/mopidy/rpc

curl -X POST -H "Content-Type: application/json" \
     -d '{"jsonrpc": "2.0", "id": 1, "method": "core.playback.stop"}' \
     http://$JUGO_HOST:6680/mopidy/rpc

curl -X POST -H "Content-Type: application/json" \
     -d '{"jsonrpc": "2.0", "id": 1, "method": "core.playback.play"}' \
     http://$JUGO_HOST:6680/mopidy/rpc
```

## Setup service
Create the env file:
```bash
nano /home/$JUGO_USER/.config/mopidy/spotify.env
```

Set credentials:
```
SP_CLIENT=your_client_id_here
SP_SECRET=your_client_secret_here
```

Create the service file:
```bash
sudo nano /etc/systemd/system/jugobox.service
```

Add configuration:
```toml
[Unit]
Description=Jugobox Service
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=<your user>
WorkingDirectory=/home/<your user>/jugobox
EnvironmentFile=/home/<your user>/.config/mopidy/spotify.env
ExecStart=/home/<your user>/jugobox/.venv/bin/mopidy -vv \
    -o "spotify/client_id=${SP_CLIENT}" \
    -o "spotify/client_secret=${SP_SECRET}"
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

Reload daemon and start the service:
```bash
sudo systemctl daemon-reload
sudo systemctl enable jugobox.service
sudo systemctl start jugobox.service
sudo systemctl status jugobox.service
```

Stop and disable the service:
```bash
sudo systemctl stop jugobox.service
sudo systemctl disable jugobox.service
sudo systemctl status jugobox.service
```
